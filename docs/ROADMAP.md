# ML engineering roadmap

Current implementation: local browser hand landmarks, webcam/video, JSON evidence export, manual notes, session metadata API.

Future:
- WLASL isolated ASL baseline, signer-independent evaluation.
- How2Sign continuous ASL research dataset, subject to research/noncommercial license.
- Temporal Transformer or TCN recognition and gloss WER evaluation.
- Grounded English translation with human evaluation and uncertainty abstention.
- Reproducible experiment tracking, model cards, privacy reviews, Docker deployment.

**Hand tracking is not sign-language translation.** Do not represent annotations as AI predictions.
