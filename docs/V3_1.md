# V3.1 playback and live tracking

Install FFmpeg on macOS: `brew install ffmpeg`. Install Python requirements from backend and ml, and launch FastAPI and Vite as in V3.0.

**Uploaded videos:** the backend converts the OpenCV MP4 to H.264/yuv420p with faststart. Results play in the new Full Pipeline panel when the job completes. Each candidate timestamp is clickable. Re-run the video to generate a browser-compatible preview; older jobs created before V3.1 have no browser_preview.mp4.

**Live camera:** Live Studio now has a separate **Live multi-signer tracking** panel. Start tracking to send resized JPEG frames to local FastAPI (~1.4 frames/s maximum). YOLO11n BoT-SORT estimates track IDs, MediaPipe extracts hands from person crops. Both bounding boxes and hand skeletons overlay the live video. This is *not* full-speed streaming, does not run face/pose extraction or GestureSign, and does not produce ASL transcription. The original browser HandLandmarker viewer remains separately available below.

Security: use only on a trusted local machine. Uploaded videos and webcam frames are sent to the local FastAPI service. There is no authentication or production isolation. Heavy CPU inference may reduce update rate.

Check: `npm run build`, `python -m compileall backend`, and a short upload test.
